# Инструкции Claude Code для команды МФТИ

Начни с README.md, docs/14-team-kickoff.md, docs/15-architecture.md и своей инструкции в docs/team/.
Подтверждённые требования — docs/12-expert-answers.md. Не меняй направление: одно резюме → набор вакансий.
AGENTS.md содержит общие ограничения данных и разработки. Его локальная личная память относится только к Mac владельца: не ищи её на чужом компьютере и не копируй в проект.

Разрешённый процесс: короткий план → реализация в основной сессии → одно независимое ревью → необходимые проверки.
Навыки — pinned Superpowers в vendor/superpowers; подключение: python3 scripts/setup_claude.py.
Основная сессия может работать на доступной модели подписки Егора; для сложных решений и ревью использовать Opus, как попросил владелец.
Правила экономных Codex-моделей из AGENTS.md не являются настройками моделей Claude: здесь исследователь hackathon-scout использует haiku, ревьюер hackathon-opus-reviewer — opus.
Максимум один помощник одновременно, максимум два запуска на ограниченную задачу, без вложенных агентов. Малые задачи выполнять самостоятельно.
Исследователь и ревьюер только читают; основной агент применяет исправления. Проверки запускает основная сессия.
Не устанавливать отдельную оркестрационную платформу. Не применять subagent-driven-development по умолчанию.
Не подключать платные модельные API ради разработки; использовать личную подписку. API продукта — отдельный бюджет.
Никаких реальных CV/личной памяти/ключей в промптах, PR, коммитах и логах. Читай только файлы своей задачи.
Не отключай защиту и проверки ради зелёного теста. Не устанавливай bypass permissions.
Не меняй контракт, формулу и границу приватности без явного решения тимлида; предложи изменение с причиной.
Не публикуй код и не отправляй сообщения автоматически. Никаких автоматических слияний в main.
В отчёте: результат, файлы, проверки, ограничения, что требуется от другого участника.
