# Учебная проверка агентов

Это синтетическая задача для проверки оркестрации, не продукт хакатона.
Функция percentage должна возвращать процент от 0 до 100.
Для 25 баллов из 50 ожидаем 50.0. Для 0 из 50 ожидаем 0.0.
maximum должен быть положительным; points должен лежать от 0 до maximum.
Недопустимые значения должны вызывать ValueError.

Исследователь читает только этот бриф и score.py, описывает контракт и варианты проверки.
Ревьюер независимо читает эти же два файла, ищет расхождения и сообщает конкретные примеры.
Оба работают только на чтение. Главный агент принимает результаты и исправляет код.
