Откройте отчёт

Выберите report.json из папки запуска, чтобы увидеть рейтинг и проверить основания оценки. Файл читается на этом устройстве.

Как получить пример отчёта

Выполните команду из корня проекта и откройте report.json в папке, указанной в выводе.

python -m prototype demo --scenario disputed
