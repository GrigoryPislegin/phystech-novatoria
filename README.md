# Хакатон Физтеха · Nanimai

Приватный репозиторий команды для HR-кейса №3 хакатона «ИИ в системе управления МФТИ», 11–15 ноября 2026 года: сравнение резюме с вакансией и показ соответствий/пробелов.

**Статус: командная база подготовлена; сквозной запуск приложения ещё не подтверждён.** Импортирован существующий код Nanimai. Frontend, Tulpa, Casino и Rocketdoc пока не получены. Код содержит известные проблемы доступа и сессий — не разворачивать на реальных персональных данных до исправления.

## Начать работу

```sh
git clone https://github.com/GrigoryPislegin/hackathon-phystech-nanimai.git
cd hackathon-phystech-nanimai
python3 scripts/check_repository.py
```

Для проверки нужен Python 3.13; установка прикладных зависимостей и ключи не нужны. Проверка проверяет синтаксис, комплектность, ссылки командной документации и типовые признаки секретов. Это не запуск приложения и не тест качества ML.

1. Прочитать [бриф](docs/01-brief.md), [сценарий МФТИ](docs/nanimai/MIPT_CASE.md) и [статус ML](docs/ML_READINESS.md).
2. Выбрать задачу из [бэклога](templates/backlog.csv), заполнить [роли](templates/team.csv).
3. Создать ветку `feature/short-name` (для Codex — `codex/short-name`), сделать Pull Request в `main`.
4. В PR указать проверку, изменение поведения и ограничения. Порядок: [CONTRIBUTING.md](CONTRIBUTING.md).
