## Сделать до старта

1. Уточнить состав команды и заполнить [роли](templates/team.csv). У каждой зоны один ответственный; один человек может совмещать роли.
2. Договориться об одном чате, месте для файлов, репозитории и том, кто отправляет результат.
3. Получить правила: допустимы ли ИИ, заготовки, внешние API; где можно обрабатывать данные.
4. Проверить ноутбуки, зарядки, интернет, доступы и запасной способ связи. Пройти [чек-лист](docs/00-preflight.md).
5. После выбора стека закрепить одинаковые версии и проверить запуск на втором компьютере.

## Когда появится условие

Передай сюда условие, регламент, дедлайн и файлы кейса. Готовый запрос:

> Разбери приложенное условие хакатона. Сначала прочитай AGENTS.md и материалы подготовки. Выпиши обязательные требования, критерии оценки, ограничения, формат сдачи и дедлайн. Заполни docs/01-brief.md, явно отметь неизвестное. Предложи один основной сценарий MVP и критерии его приёмки. Выбери подходящий стек с учётом условий и опыта команды. Подготовь короткий план, затем реализуй первый сквозной сценарий и проверь его. Применяй экономное делегирование из AGENTS.md.

В первые 60 минут использовать [бриф и порядок старта](docs/01-brief.md).

## Повторить проверку Mac

Из этой папки:

```sh
python3 scripts/doctor.py
```

Обновить локальный отчёт:

```sh
python3 scripts/doctor.py --write-report
```

Для утилиты нужен Python 3.11+ (на этом Mac установлен 3.13). Проверка не устанавливает программы, не обращается к API моделей, не читает ключи и не отправляет данные. Состояние Docker и версии инструментов проверяются заново.
