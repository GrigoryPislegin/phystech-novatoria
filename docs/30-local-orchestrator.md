# Локальный оркестратор разработки

14 ноября 2026: установлен Agetor 1.2.0 из официального release
https://github.com/alamops/agetor/releases/tag/v1.2.0.
Это инструмент разработки, не часть приложения рекрутера или его Docker image.

Установка на Mac владельца:

- приложение: `/Applications/Agetor.app`;
- CLI: `~/.local/bin/agetor`;
- tmux: встроенный в Agetor, выбран через настройки приложения;
- подключён только Codex CLI, используется существующий вход через ChatGPT;
- профиль `C14 Explorer`: `gpt-6-luna`, reasoning `high`, режим `ask`;
- проверена фактическая команда запуска: `codex exec --sandbox read-only`;
- автозапуск при входе и удалённый доступ Agetor выключены; обход лимитов и переключение аккаунтов не настроены.

Контрольные суммы загрузок совпали с release assets. Исходный DMG прошёл
проверку подписи и notarization macOS. При первой распаковке строгая проверка
подписи приложения дала ошибку; последующая обычная проверка `codesign --verify --deep`
и Gatekeeper приняли установленное приложение. Это не полный аудит стороннего продукта.

## Проект и первый проверенный запуск

Исходный linked worktree ссылается на Git metadata в `Documents`, которую дочерний
процесс Agetor не смог открыть. Права macOS не расширялись. Для агентов клонирована
уже опубликованная ветка `codex/c14-safe-mvp` в `~/.agetor/projects/nanimai-c14`.
Приватные файлы, `.env`, реальные CV и личная память в эту копию не переносились.

Задача `0b57e49a-40de-4a8d-8611-e82173771fe2` стартовала с `b2e0e5f` в отдельном
worktree и завершилась `succeeded`, exit 0. Результат принят, карточка перемещена в Done.
Агент изучил `pipeline.py`, `model.py`, `local_service.py` и связанные тесты без правок.
Подтвердил, что 61 последовательный model call ограничен общим deadline 300 секунд,
а `cancel()` не прерывает уже ожидаемый запрос. Это анализ кода, не live-замер качества или скорости.

Вторая задача `627bbc06-0128-48ae-940d-2cb75b142239` — read-only ревью патча отмены,
профиль `C14 Reviewer`, `gpt-6.1-sol`/medium/ask. Агент воспроизвёл гонки при повторной
отмене и дедлайне во время асинхронной очистки. Root исправил код и добавил тесты;
адресная перепроверка закрыла замечания. Оба запуска через Agetor завершились с exit 0.
Платный API продукта не использовался; его модель остаётся Luna.

```bash
~/.local/bin/agetor ps
~/.local/bin/agetor ls
~/.local/bin/agetor logs 0b57e49a --no-follow
```

Следующие задачи должны иметь отдельную зону ответственности и проверяемый результат.
Текущие инструкции проекта ограничивают работу одним активным помощником; не запускайте
дубли скоринга Егора или интерфейса Вани. Изменения принимает и проверяет основной агент.
Режим Agetor `auto` для linked worktree не используется: эта версия может автоматически
выбрать `danger-full-access`. Для исследователя сохраняется `ask`/read-only.

Официальная документация поддерживает автоматизацию `codex exec` и сохранённую
авторизацию CLI: https://learn.chatgpt.com/docs/non-interactive-mode.
Это не означает отдельного одобрения Agetor со стороны OpenAI.
