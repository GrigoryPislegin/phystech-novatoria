| Нет доступа к API | Контролируемая ошибка; заранее сохранённый пример ответа с явной пометкой |

| Сломалась сборка | Возврат к известной рабочей версии; не делать массовые обновления перед защитой |
| Ссылка недоступна | Проверенная резервная ссылка или архив в допустимом формате |

Накануне сдачи сохранить 60–90 секунд видеодемо, ключевые скриншоты, входные данные и команду запуска. Заглушки и запись должны быть названы заглушками и записью.
