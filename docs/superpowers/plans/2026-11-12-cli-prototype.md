# CLI прототип: план реализации

> Исполнитель: основная сессия, executing-plans; один исследователь и одно итоговое независимое ревью.

**Goal:** до консультации 13 ноября в 14:00 МСК получить воспроизводимый путь «резюме → несколько вакансий → объяснимый отчёт».

**Architecture:** локальное извлечение текста, адаптер настоящих детекторов Certum, структурированные ответы OpenAI, проверка цитат, детерминированный скоринг. Отдельный встроенный синтетический пример работает без API; он не выдаётся за результат модели.

**Tech Stack:** Python 3.12+; Pydantic 2, OpenAI SDK, pdfplumber, python-docx. Для настоящего Certum — Python 3.12 и уже настроенный core с PostgreSQL и сейфом.

**Spec:** docs/12-expert-answers.md, docs/13-product-flow-v02.md; решения владельца 12 ноября: без UI и Docker на первом этапе, $74 общий бюджет, Luna или Sol, защита Глеба, новых комплектов кода не будет.

## Global Constraints

- Никаких вызовов платного API при подготовке без ключа. Ключ не запрашивать в чате.
- Модель выбирается явно: gpt-6-luna / gpt-6.1-sol; автоматического переключения нет.
- Реальные файлы не отправлять без Certum. Отсутствие настройки или остаточные находки останавливают запрос.
- Не считать детекторы доказательством полной анонимности: косвенная идентификация остаётся ограничением.
- Четыре статуса; unknown не означает fail; обоснование каждой оценки проверяется по исходному обезличенному тексту.
- Прототип без UI, Docker, ATS и обучения. Финальные требования по Docker сохраняются.
- Существующие изменения не трогать; отдельная ветка, без публикации и автоматических коммитов.

## Review Focus

- Ошибка обработки одной вакансии не превращается в «ни одна не подходит».
- Ссылки на несуществующий факт, повторные/пропущенные требования отклоняются.
- Неизвестное обязательное требование требует уточнения, не отказа.
- Ошибка API/Certum не выводит исходный текст, ключ или DSN.
- Лимит вызовов и резерв стоимости проверяются до отправки; нет скрытых повторов.

## Журнал решений и завершения

- Работа выполнена в отдельной локальной ветке, без worktree/коммитов/публикации: сохранены текущие материалы владельца. Источник требований — документы выше и прямое разрешение первого прототипа.
- Исследователь Luna проверил API и зависимости настоящего Certum, основной агент реализовал код. Один Sol-ревьюер проверил весь срез; повторного ревью не запускали.
- Рuling: код адаптера не равен работающему контуру; PostgreSQL/tenant/vault/NER требуют отдельного запуска. До этого реальные файлы не уходят в модель.
- Рuling: review_none_fit вместо окончательного none_fit — структурная валидация не доказывает смысловое противоречие; рекрутер проверяет вывод. Числовая формула не изменена.
- Рuling: дополнительная проверка сырых ref-токенов защищает от обхода core, в котором ссылки исключены из сканирования; это не самодельная замена детекторов.
- По уточнению владельца добавлены полная архитектура, README, персональные инструкции и Opus-роль Егора; подготовлен проектный установщик Claude.
- Завершено: 22 локальных теста, replay, smoke DOCX/PDF, установка зависимостей, проверка синтаксиса и ссылок. Не выполнено: настоящий API, Certum end-to-end, второй компьютер, UI/Docker. Подробный журнал — docs/04-quality.md.
