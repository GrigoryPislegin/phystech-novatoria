1. **Обычная сборка не прошла.** `docker build -t recruiter-prototype:local .` на `60a9dc1` упал через 191 с на стадии `models-download`:
   - сообщение — `privacy_models_setup_failed:URLError`, exit 1;
   - Slovnet внутри сборки скачался примерно за 40 с, Navec оборвался примерно через 60 с;

   Это провал сборки по сети, а не PASS. NER и TLS не отключались.
2. **Сборка запасным путём из runbook прошла.**
   - `python -m prototype.privacy_core.prepare --dir <tmp>` на хосте: 52 с, `privacy_models_verified: 2`;
   - `prepare --from-dir <tmp> --dir runtime/privacy-models`: хеши проверены до копирования и после;
   - `docker build --build-arg PRIVACY_MODEL_SOURCE=local -t recruiter-prototype:local .` — exit 0.

   Тесты внутри сборки: 8 OK и 29 OK, оба `privacy_smoke` PASS.

## Не сделано

- **Скачивание HTML для менеджера (ревизия 3) и удаление одного запуска с сохранением другого.** Оба действия требуют явного разрешения владельца компьютера: скачивание файла и необратимое удаление в интерфейсе. Отложены до его ответа, поэтому приёмка не закрыта целиком.
- Готовые образы из prerelease `night-c1c1f4f` не загружались: образ собран локально из проверенного кода.
- `linux/amd64` на этом компьютере не запускался. Эмуляция на arm64 не заменила бы второй компьютер с другой архитектурой.
- Запуск из исходников (без Docker) проверен на `4b36bed` в #20: Python 3.14 вместо 3.13, без NER.

На втором компьютере Docker-образ проверенного кода работает:

- D1 — некорректный останов контейнера.
