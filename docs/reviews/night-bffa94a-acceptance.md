## Что изменилось в выборе вакансии

Дословные повторы считаются одной единицей с учётом цитаты и обязательности. Противоречащие статусы повторов требуют проверки: они не превращаются в положительный аргумент в UI, Markdown, CSV или пакете менеджера. Обязательные/прочие требования получают фиксированные доли 75/25; при наличии только одной группы — 100. Это проверяемая гипотеза команды, не веса, утверждённые экспертом.

Объяснение показывает до трёх оснований первого места, ограничения и уточнения, способные изменить выбор. Проверка устойчивости охватывает спорные основания и не более двух ответов кандидата; это допущение видно в интерфейсе. Расчёт использует точные дроби до отображения; округление не меняет порядок. При большем числе неподтверждённых маркеров обязательности анализ остаётся консервативным. Семантически похожие, но разные формулировки автоматически не объединяются.

Объяснения и дашборд строятся из отчёта без новых LLM-вызовов. Старые отчёты v2 не пересчитываются и не получают подтверждение новой политики от старого решения HR.

## Docker и независимый CI

Оба образа собраны из bffa94a с проверенными публичными весами: **arm64 и amd64 PASS**. При сборке каждого выполнены 8 core +30 integration и оба privacy smoke. SDK MockTransport: 7 локальных запросов, 3/3 вакансии, 0 внешних вызовов. Экспорт архива и фактический `docker load` обоих тегов прошли.

```sh
docker run --rm --network none --entrypoint python recruiter-prototype:bffa94a-arm64 scripts/check_cli_replays.py --without-ui
python3 scripts/check_container_stop.py --image recruiter-prototype:bffa94a-arm64
```

Обе команды PASS; те же проверки с тегом `bffa94a-amd64` и `--platform linux/amd64` также PASS. Штатный stop завершает контейнер с кодом 0. Независимые [Repository CI](https://github.com/GrigoryPislegin/hackathon-phystech-nanimai/actions/runs/43524689576) и [Linux amd64 Docker CI](https://github.com/GrigoryPislegin/hackathon-phystech-nanimai/actions/runs/43524689571) — success на точном bffa94a. В Docker CI проверены сборка, offline CLI, store/service/HTTP, NER/SDK mock и stop.

Второй физический Mac проверен Егором на предыдущем **48268b2**, включая экспорт, restart и замену образа с сохранением тома. Этот результат не приписывается bffa94a. На Mac Егора download весов потребовал checksum-verified fallback. Windows физически не проверялся.

## Что осталось неподтверждённым

- Качество новой live-модели, сложное отрицание/контекст/стаж на независимой выборке, согласие реальных HR и экономия времени рекрутера. Новых платных API-прогонов не было.
- Полнота защиты реальных CV. [N-C3](privacy-acceptance-2026-11-14.md): 19/19 синтетических идентификаторов скрыты, 24/28 профессиональных фрагментов сохранены; четыре потери текста остаются явными.
- Согласование внешней обработки с техническим специалистом заказчика. Реальные CV во внешний API не отправлялись.
- Утренняя командная репетиция, доступ жюри к приватному репозиторию/артефактам и фактическая подача командой. Ночная поставка не равна автоматической сдаче конкурса.
