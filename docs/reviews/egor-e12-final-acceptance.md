## 3. Демонстрация за 90 секунд

1. **0–15 с.** «Запуски» → «Подходящая вакансия» → «Запустить». Один кандидат, три вакансии, ответы синтетические.
2. **15–40 с.** «Сводка»: первое место `job-001`, два основания с цитатами. Показать `job-002`: «сведения не указаны — это не отказ», и `job-003`: явное несоответствие по стажу.
3. **40–60 с.** «Подтвердить состав» → «Отметить для передачи» → «Отчёт для менеджера»: в шапке «Проверено рекрутером · Ревизия 3».
4. **60–80 с.** Спорный сценарий: «первое место предварительное», один вопрос кандидату про Go помечен как способный изменить выбор.
5. **80–90 с.** Неполный сценарий: передача заблокирована.

**Без сети.** Сеть не нужна: replay работает локально. Если не открывается браузер — `python -m prototype demo --scenario success` и `disputed`, заранее сохранённый `manager-report.html` и `python -m evaluation.policy_compare`.

**Одна разница v2/v3 (E11-13, фактический расчёт).** Две вакансии, у обеих подтверждён обязательный Python. v2: 80 против 70, вывод «проверьте лидера». v3: 87,5 против 81,25, вывод «уточнить», решающая строка — PostgreSQL у второй вакансии: о ней нет сведений, а положительный ответ даёт 93,75 и меняет первое место. Проще: v2 не замечала, что один вопрос кандидату переворачивает выбор; v3 называет этот вопрос.

## 4. Вероятные вопросы жюри

1. **Откуда число?** Версионированная формула: обязательные требования — 75 пунктов, остальные — 25; статус каждой строки предложен моделью и привязан к цитате. Это не вероятность найма.
2. **Что если модель ошиблась?** Структуру цитаты проверяет код, смысл — рекрутер; спорная строка не входит в нижнюю границу; решение записывает только HR, с ревизией.
3. **Чем «нет сведений» отличается от «не подходит»?** Разные статусы: unknown расширяет диапазон (0–100%) и порождает вопрос; несоответствие требует явной фразы в резюме.
4. **Как доказано, что v3 лучше?** На 16 вымышленных случаях с заранее записанными ожиданиями v2 проходит 10, v3 — 16. Это проверка логики правил, не точность модели.
5. **Что с персональными данными?** Защита локальная и останавливает отправку при сбое; реальные CV во внешний API не отправлялись. Анонимность не гарантируется.
