# Локальный экран рейтинга Nanimai

Первый экран V3 читает сохранённый отчёт в браузере. Он показывает порядок вакансий, диапазон оценки, статус обработки и основания по требованиям. Рейтинг берётся из файла. Выводы версии 0.1 требуют проверки рекрутером.

## Открыть демо

Из корня репозитория в установленном окружении прототипа:

```sh
python -m prototype demo --scenario success
python -m prototype demo --scenario disputed
python -m http.server 8767 --bind 127.0.0.1 --directory prototype/static
```

Откройте в браузере [127.0.0.1:8767](http://127.0.0.1:8767/), нажмите «Открыть отчёт» и выберите `report.json` из папки, которую показал CLI. Для быстрого просмотра можно выбрать `prototype/tests/fixtures/web/disputed.json`. Чтобы остановить сервер, нажмите Ctrl+C. Сервер раздаёт только HTML, CSS и JavaScript. Браузер читает выбранный JSON локально, без отправки файла.

## Проверить результат

- `success` показывает полное соответствие, «не указано» и несоответствие. `disputed` показывает частичное соответствие по обязательному требованию.
- В спорном примере первая вакансия выбрана автоматически. После выбора файла нажмите «Обязателен опыт Python и Go.» и увидите рядом исходные фразы и вопрос кандидату. Можно открыть строку клавишей Enter.
- `prototype/tests/fixtures/web/incomplete.json` показывает одну из трёх вакансий, причины пропуска двух остальных и предварительное место.
- Сравните число вакансий до и после фильтрации. Поиск и фильтры меняют видимость строк требований.
- `node --test prototype/tests/test_web_report.cjs` проверяет совместимость отчётов, статусы, ничьи, фильтрацию и обработку неверного входа. Требуется Node.js с встроенным модулем `node:test`. Страница запускается в браузере с обычным Python-сервером и не требует Node.js.

## Границы V3

Поддерживается версия отчёта 0.1, до 25 МБ, с подготовленным представлением и в старом формате. Экран показывает идентификаторы вакансий из отчёта. Локальный манифест с именами входных файлов хранится отдельно. В старом отчёте комментарии и вопросы модели помечены как непроверенные. В отчёте с `presentation` экран использует подготовленные пояснения и черновики вопросов. Он сверяет строки и цитаты с исходными полями отчёта, показывает результат структурной проверки и отмечает обязательные требования, которые движок учёл с обычным весом. Смысл цитат проверяет рекрутер.

Запуск анализа из браузера и подтверждение требований относятся к следующим этапам. Печатный пакет выбранной вакансии описан в [инструкции V5](vanya-v5-manager-report.md). Для V3 достаточно синтетических примеров.
