# Экран AI-рекрутера по макетам Nanimai

Откройте `prototype/static/index.html` локально и нажмите «Открыть демо». Для отчёта CLI выполните `python -m prototype demo --scenario disputed`, затем выберите сгенерированный `report.json`. В режиме локального веб-сервера вкладка «Запуски» появляется после ответа `/api/session` с доступными операциями.

## Визуальный перенос

- Из `Вакансии.svg` перенесены светлый каркас, действия справа от заголовка, переключатель разделов, ряд карточек с разделителем и контурной кнопкой, тёмная поверхность подвала. На исходных 1728 единицах сетка имеет четыре колонки, рабочая область ограничена 1430 пикселями. При меньшей ширине сетка складывается.
- Из `Компоненты.svg` перенесены светлая панель анализа и серый блок вывода, статусные плашки и раздельные ячейки критериев, цветовые предупреждения. Строки раскрывают фрагменты вакансии и резюме рядом. На узком экране цитаты идут друг под другом.
- Сводка и секция объяснения места построены на компонентах макетов и адаптированы к контракту отчёта. Сводка показывает L–H, долю известных данных и четыре числа статусов. Объяснение места берёт пару вакансий, причину, цитаты, оговорки и варианты уточнений из отчёта E7. Импортированные идентификаторы с произвольной строкой заменяются безопасными названиями, а сравнение сверяет ссылки на требования с принятыми строками отчёта.
- Типографика приближена системным sans-serif. Название шрифта из SVG с контурами не установлено. Проверены два референса, перечисленные выше. Полной пиксельной сверки всех экспортов не проводилось. В интерфейсе и менеджерском экспорте используется обычный текст «AI-рекрутер».

## Поведение

- Офлайн-просмотр открывает сохранённый JSON либо встроенный вымышленный пример. Разбор, фильтрация, просмотр цитат и выгрузка менеджерского HTML работают локально. Макеты и личные данные из макетов в сборку не входят.
- Контролы локальных запусков и проверок зависят от возможностей, выданных сервером. Сохранение решения использует версию отчёта. При конфликте версии интерфейс перечитывает отчёт, а повторное действие инициирует рекрутер. Импортированный отчёт доступен только для чтения.
- Режимы replay, Mock SDK и live подписаны отдельно. Документы можно проверить локально. Действие защищённого внешнего анализа доступно при отдельном разрешении сервера и требует явного подтверждения с указанным лимитом. Проверка на стороне браузера не подтверждает смысл цитат и не меняет оценки.
- Менеджерский отчёт показывает ревизию локального запуска. Статус «Проверено рекрутером для передачи» берётся только из текущего отчёта собственного API. Исключения, конфликтующие условия и неизвестные сведения сохраняются. Импортированный отчёт экспортируется как черновик.

## Приёмка

- `node --test prototype/tests/*.cjs` прошла (36 тестов). Новые проверки покрывают частичный запуск, диапазоны и статусы, соответствие сравнения цитатам, режим локальной сессии и HTTP-методы/CSRF.
- Chromium проверен на 1728, 1440, 1280, 720, 390 и 320 CSS-пикселях. Проверены выбор вакансии с клавиатуры, фокус заголовка разбора, 200% масштаб инструмента эмуляции, профиль, конфликт условий, сводка, импорт неполного отчёта и отказ при ошибочном JSON с сохранением предыдущего просмотра.
- Строка с HTML отобразилась буквально в интерфейсе и в PDF. Проверена двухстраничная печать A4 с длинной цитатой. На отчёте текущего CLI проверены сравнение по L и по правилу обязательных требований, цитаты и предупреждение о разных списках.
- Браузерная проверка HTTP проведена с локальным тестовым сервером по согласованному контракту. Проверены запуск, обновление состояния, открытие, конфликт версий, явный повтор сохранения, очередь, удаление, передача синтетических UTF-8 документов, результат по каждому файлу и отключённый внешний анализ. Повторная проверка Chromium прошла на настоящем loopback-сервере интеграционной ветки. Локальная проверка документов с выключенным внешним анализом, replay 3 из 3, подтверждение состава и отметка для передачи, загрузка менеджерского HTML ревизии 3, повторное открытие, удаление и неполный replay с блокировкой передачи работали через серверные маршруты. Защищённый Mock SDK обработал 3 из 3 вакансий, транспорт — `local_mock`, счётчик внешних вызовов — 0. В браузере не было исключений JS и нарушений CSP.

## Подтверждение удаления и решения HR

Для удаления взят кадр «Подтвердите удаление» из `Вакансии.svg` (`clip11_0_1`, начало x=4315, y=355). Для подтверждения состава требований использована компоновка соседнего кадра «Подтвердите архивирование» (`clip7_0_1`, начало x=2356, y=355). В `Компоненты.svg` проверены компоненты анализа и уведомлений из предыдущей приёмки. Источник для обоих окон — `Вакансии.svg`.

В Chromium на 1728 × 1181 CSS-пикселях и DPR 1 обе панели совпали с исходником по координатам и размеру (x=606, y=250, 516 × 224 px), радиусу 16 px и чёрному затемнению 50%. Действия расположены в x=850 и x=982 на y=398. Размер каждой кнопки 120 × 48 px, радиус 14 px, промежуток 12 px. У «Отмены» прозрачная граница и тёмный текст. У удаления цвет `#F3125F` из исходника. Для подтверждения состава требований использован основной акцент `#4D61F4`. Белый текст на исходном розовом даёт контраст около 4,15:1. Системный шрифт, формулировки про локальный отчёт и обводка клавиатурного фокуса отличаются от исходных кадров.

На 390 × 844 CSS-пикселях обе панели заняли 360 px по ширине и сохранили две кнопки в строке. На встроенном синтетическом запуске через приложение Chromium проверены начальный фокус на «Отмене», переход Tab на подтверждение, закрытие через Escape, «Отмену» и кнопку «Закрыть» (×), возврат фокуса к вызвавшей кнопке и сохранение ревизии при отмене. Подтверждение состава увеличило ревизию на одну, подтверждение удаления удалило тестовый запуск, прежняя история сохранилась. В интерфейсе видна текстовая подпись «AI-рекрутер» без знака. Внешний анализ был отключён. Прошли 36 тестов `node --test prototype/tests/*.cjs`.
