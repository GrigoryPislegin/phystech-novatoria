PDF имеют текстовый слой, OCR этим не проверяется. Новый общий тест `prototype.tests.test_e6_documents` реально читает каждый PDF/DOCX, сравнивает SHA256 и точный текст с текущим E6. Все девять файлов PASS. Команда:

```sh
.venv/bin/python -m unittest prototype.tests.test_e6_documents -v
```

- P2: удалённый conditions в современном E6-FA-04 давал checked, ожидаемый конфликт становился not_run без ошибки. Воспроизведено reviewer.
- P2: чтение case-файлов и запись summary через существующие symlink могут выйти из выбранных каталогов. Установлено по коду, CLI-эксплуатация не запускалась.

Находки и границы принятия переданы в PR. Полный PR не объявляется слитым. У V6 есть полезные дополнительные проверки источников, profile/conditions и projection consistency; их перенос в единственный E9 evaluator — отдельный последующий этап, не выполненная часть этой поставки.
